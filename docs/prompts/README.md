# Промты для ИИ-помощников

← [команда](../team.md)

Здесь два готовых промта: для участника «Железо» и для участника «Софт и защита». Промт превращает любой чат-ИИ (Claude, ChatGPT и другие) в личного наставника по проекту STARYS. Он:

- объясняет, **зачем** нужна каждая задача и как она связана с роем;
- ведёт по шагам и проверяет, что шаг получился;
- сначала даёт попробовать самому, а если не выходит — делает сам, но **подробно объясняет, что и почему сделал**;
- в конце каждого занятия пишет **отчёт**, который можно сразу отправить лиду.

| Участник | Промт |
|---|---|
| «Железо»: схема, датчики, 3D | [zhelezo.md](zhelezo.md) |
| «Софт и защита»: тесты, веб, данные | [soft.md](soft.md) |

## Как пользоваться

1. Открой свой файл, скопируй **весь текст внутри блока** (между строками с ```).
2. Начни новый чат с ИИ и вставь этот текст первым сообщением.
3. Ответь на вопросы ИИ: что ты уже умеешь, сколько времени есть сегодня.
4. Работай по шагам. Если ИИ не может открыть ссылку на файл, открой файл на GitHub сам и вставь его текст в чат.
5. В конце занятия напиши «отчёт» — ИИ соберёт отчёт. Вставь его в Issue «Неделя N» на GitHub.

Один чат = одна задача. Для новой задачи лучше начать новый чат и снова вставить промт, написав в конце, какая задача сейчас.

Если репозиторий приватный, ИИ не сможет открыть ссылки — попроси лида добавить тебя в репозиторий и копируй файлы в чат вручную.
