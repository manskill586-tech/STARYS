# Команда: роли и задачи

← [на главную](../README.md)

Два опытных участника отвечают за логику и связь, два новичка — за «тело» модуля и проверку. У каждого новичка есть наставник из опытных. Если вас трое, лид берёт на себя и протокол связи.

| Роль | Кто | Наставник | Зона ответственности | Главные файлы |
|---|---|---|---|---|
| 1. Лид прошивки | опытный | — | конечный автомат, структура кода, сборка частей в одно целое | [`swarm_core.h`](../firmware/src/swarm_core.h) |
| 2. Связь и протокол | опытный | — | MQTT, формат сообщений, рукопожатие, тайм-ауты | [`main.cpp`](../firmware/src/main.cpp), [`protocol.md`](protocol.md) |
| 3. Схема и индикация | новичок | роль 1 | схема в Wokwi, светодиод, кнопки, датчик, сервопривод | [`diagram.json`](../firmware/wokwi/module1/diagram.json), [`hardware/`](../hardware) |
| 4. Тесты и защита | новичок | роль 2 | сценарии проверки, видео, презентация | [`test_core.cpp`](../firmware/test/test_core.cpp), [`demo.md`](demo.md) |

## Роль 1 — Лид прошивки

- [x] Нарисовать автомат: состояния, переходы, условия → [architecture.md](architecture.md)
- [x] Создать репозиторий на GitHub и каркас кода: `enum class State` + `switch` в `tick()`
- [x] Реализовать переходы между состояниями без `delay()`, на `millis()`
- [ ] Каждую неделю проводить короткий код-ревью для новичков

## Роль 2 — Связь и протокол

- [x] Описать сообщения HELLO, DOCK_REQ, DOCK_ACK, DATA, BYE в формате JSON → [protocol.md](protocol.md)

## Материалы для старта

Новичкам хватит первой недели, если идти по порядку.

1. [Wokwi](https://wokwi.com) — открыть готовый пример ESP32 Blink и поменять в нём цвет и частоту мигания.
2. [Документация Wokwi](https://docs.wokwi.com) — разделы про кнопки, RGB-светодиод, HC-SR04 и сервопривод.
3. Основы Arduino: `setup()`, `loop()`, `digitalWrite`, `digitalRead`, `millis()` вместо `delay()`.
4. Конечный автомат на Arduino: ищите на YouTube «Arduino state machine switch case». Потом прочитайте [`swarm_core.h`](../firmware/src/swarm_core.h) — там то же самое, только аккуратно.
5. Для роли 2: библиотеки PubSubClient (MQTT) и ArduinoJson.

**Правило команды:** любой вопрос — сначала 20 минут поиска, потом сразу к наставнику.
